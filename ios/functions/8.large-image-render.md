在 iOS 中处理“超大图”，核心是解决内存瓶颈，**实现靠“分块按需加载”，保存靠“位图上下文渲染”**。具体解释如下：

### 1. 核心实现原理：“分块”与“按需”
iOS 内存有限，无法一次性加载 16K 纹理（可能超 1GB）。超大渲染原理就是 **Sparse Texture（稀疏纹理）** ：

*   **分块与驻留**：把大图切成小块（Tile）及 Mipmap 层级。只加载当前屏幕需要的块（驻留），释放远的块。
*   **动态更新**：GPU 会记录每块被访问的次数。App 据此决定加载新块还是淘汰旧块，实现流畅浏览。
*   **硬件要求**：该技术需要 **A13 芯片及以后**的设备支持（`MTLGPUFamilyApple6`）。

### 2. 如何实现：“截图” vs “渲染”
*   **长图截屏（UIView 级别）**：适合生成包含`UIScrollView`等控件的内容。通过`UIGraphicsImageRenderer`创建等于`contentSize`的上下文，分页调用`drawViewHierarchyInRect`拼接渲染，最后合成。
*   **图片解码（CGImageSource 级别）**：适合处理超大的 JPEG/PNG。使用 `Image I/O` 框架，只解码图片的特定区域，避免将整个原始图放入内存。

### 3. 保存超大图的关键
*   **生成 `UIImage`**：通过**位图上下文** (`UIGraphicsImageRenderer`) 绘制得到。注意单张 `UIImage` 的像素限制（如 WidgetKit 限制约 71.8 万像素）。
*   **写入文件**：生成后转为 `Data`（如 `jpegData`），直接写入磁盘（`Documents` 目录）。**注意**：保存到相册时，系统可能因内存不足而崩溃，建议先保存到 App 沙盒，再通过 `PHPhotoLibrary` 以文件路径方式导入。

另外，使用 `UIGraphicsImageRenderer` 时注意添加 `@autoreleasepool` 及时释放内存，防止 OOM。

### 场景 A：超长滚动截图（UIScrollView + 分块拼接）
**原理**：不一次性绘制整个 contentSize，而是按屏幕高度分块逐帧绘制，避免内存暴涨。

```swift
import UIKit

extension UIScrollView {
    func captureLongScreenshot(quality: CGFloat = 0.9) -> UIImage? {
        let savedOffset = contentOffset
        let savedFrame = frame
        
        // 1. 计算总尺寸
        let totalSize = contentSize
        let pageHeight = frame.height // 每块高度取屏幕高度
        
        // 2. 关闭滚动、开启分页模式
        isScrollEnabled = false
        frame = CGRect(origin: .zero, size: totalSize)
        
        let renderer = UIGraphicsImageRenderer(size: totalSize)
        let image = renderer.image { context in
            var currentY: CGFloat = 0
            while currentY < totalSize.height {
                autoreleasepool {
                    // 移动到对应区域绘制
                    contentOffset = CGPoint(x: 0, y: currentY)
                    // 只绘制当前可见块
                    let rect = CGRect(x: 0, y: currentY, 
                                      width: totalSize.width, 
                                      height: min(pageHeight, totalSize.height - currentY))
                    self.drawHierarchy(in: rect, afterScreenUpdates: true)
                }
                currentY += pageHeight
            }
        }
        
        // 3. 恢复状态
        contentOffset = savedOffset
        frame = savedFrame
        isScrollEnabled = true
        
        return image
    }
}
```

### 场景 B：生成并保存超大纯色海报（8000x6000）
**原理**：使用 `UIGraphicsImageRenderer` 直接绘制矢量路径，内存消耗仅与画布尺寸相关，且自动释放临时缓存。

```swift
import UIKit

func generateLargePoster() -> UIImage? {
    let size = CGSize(width: 8000, height: 6000)
    
    let renderer = UIGraphicsImageRenderer(size: size)
    return renderer.image { context in
        // 绘制背景
        UIColor.white.setFill()
        context.fill(CGRect(origin: .zero, size: size))
        
        // 绘制一个红色圆（矢量绘制，不占用大内存）
        UIColor.red.setFill()
        let circleRect = CGRect(x: 1000, y: 1000, width: 2000, height: 2000)
        context.cgContext.fillEllipse(in: circleRect)
    }
}

// 保存到沙盒并防止 OOM
func saveHugeImage() {
    guard let image = generateLargePoster() else { return }
    
    // 关键步骤：不保存到相册，而是直接写文件
    if let data = image.jpegData(compressionQuality: 0.8) {
        let path = FileManager.default.temporaryDirectory
            .appendingPathComponent("huge_poster.jpg")
        try? data.write(to: path)
        print("保存成功：\(path)")
    }
}
```

### ⚠️ 最重要的注意事项
1. **绝对不要用 `UIImage(data:)`** 加载原始超大图，必须使用 `CGImageSource` 分块解码。
2. 保存相册（`PHAsset`）时，系统会对图片进行二次压缩和转码，极易因内存不足被杀。**推荐只存沙盒**，用户需要时通过 `UIDocumentPickerViewController` 导出。
3. 生成超大图时，务必在 `@autoreleasepool` 包裹的循环内执行绘制，否则内存峰值会翻倍。

## 系统图片瓦片式加载方案

针对**系统图片分块加载**（处理已存在的超大 JPEG/PNG 文件），核心是 **`CGImageSource` + 缩略图分块**。下面给你可直接运行的源码，分别实现**按需加载可见区域**和**生成降采样预览图**。

### 核心源码：分块加载指定区域

```swift
import UIKit
import ImageIO

class TileLoader {
    private let imageSource: CGImageSource
    private let fullImageSize: CGSize
    
    init?(fileURL: URL) {
        guard let source = CGImageSourceCreateWithURL(fileURL as CFURL, nil) else {
            return nil
        }
        self.imageSource = source
        
        // 获取原始图片尺寸（不加载像素数据）
        guard let properties = CGImageSourceCopyProperties(source, nil) as? [CFString: Any],
              let width = properties[kCGImagePropertyPixelWidth] as? CGFloat,
              let height = properties[kCGImagePropertyPixelHeight] as? CGFloat else {
            return nil
        }
        self.fullImageSize = CGSize(width: width, height: height)
    }
    
    /// 加载图片的指定矩形区域（单位：像素）
    func loadTile(rect: CGRect, scale: CGFloat = 1.0) -> UIImage? {
        // 1. 创建缩略图选项，只解码指定区域
        let options: [CFString: Any] = [
            kCGImageSourceCreateThumbnailFromImageIfAbsent: true,
            kCGImageSourceThumbnailMaxPixelSize: max(rect.width, rect.height),
            kCGImageSourceCreateThumbnailWithTransform: true,
            // 关键：指定裁剪区域（归一化坐标 0~1）
            kCGImageSourceImageRect: CGRect(x: rect.minX / fullImageSize.width,
                                            y: rect.minY / fullImageSize.height,
                                            width: rect.width / fullImageSize.width,
                                            height: rect.height / fullImageSize.height) as CFRect
        ]
        
        // 2. 生成缩略图（只解码需要的像素）
        guard let cgImage = CGImageSourceCreateThumbnailAtIndex(imageSource, 0, options as CFDictionary) else {
            return nil
        }
        
        return UIImage(cgImage: cgImage, scale: scale, orientation: .up)
    }
    
    /// 生成低分辨率预览图（用于快速展示整体）
    func loadPreview(maxPixelSize: CGFloat = 512) -> UIImage? {
        let options: [CFString: Any] = [
            kCGImageSourceCreateThumbnailFromImageIfAbsent: true,
            kCGImageSourceThumbnailMaxPixelSize: maxPixelSize,
            kCGImageSourceCreateThumbnailWithTransform: true
        ]
        
        guard let cgImage = CGImageSourceCreateThumbnailAtIndex(imageSource, 0, options as CFDictionary) else {
            return nil
        }
        return UIImage(cgImage: cgImage)
    }
}
```

```swift
class TileViewController: UIViewController, UIScrollViewDelegate {
    private let scrollView = UIScrollView()
    private let imageView = UIImageView()
    private var tileLoader: TileLoader?
    
    override func viewDidLoad() {
        super.viewDidLoad()
        
        // 1. 初始化分块加载器
        let url = Bundle.main.url(forResource: "huge_image", withExtension: "jpg")!
        tileLoader = TileLoader(fileURL: url)
        
        guard let loader = tileLoader else { return }
        
        // 2. 设置 ScrollView
        scrollView.delegate = self
        scrollView.contentSize = loader.fullImageSize
        scrollView.minimumZoomScale = 0.1
        scrollView.maximumZoomScale = 1.0
        scrollView.addSubview(imageView)
        view.addSubview(scrollView)
        
        // 3. 加载初始可见区域
        updateVisibleTile()
    }
    
    func scrollViewDidScroll(_ scrollView: UIScrollView) {
        updateVisibleTile()
    }
    
    private func updateVisibleTile() {
        guard let loader = tileLoader else { return }
        
        // 获取当前可见区域（转换为像素坐标）
        let visibleRect = scrollView.bounds
        let pixelRect = CGRect(x: visibleRect.minX * scrollView.zoomScale,
                               y: visibleRect.minY * scrollView.zoomScale,
                               width: visibleRect.width * scrollView.zoomScale,
                               height: visibleRect.height * scrollView.zoomScale)
        
        // 加载该区域的图像（加入 autoreleasepool 防止临时内存堆积）
        autoreleasepool {
            if let tileImage = loader.loadTile(rect: pixelRect, scale: UIScreen.main.scale) {
                imageView.frame = pixelRect
                imageView.image = tileImage
                imageView.contentMode = .scaleAspectFit
            }
        }
    }
}
```

### 关键原理解释

| 参数/API                              | 作用                                           |
| ------------------------------------- | ---------------------------------------------- |
| `CGImageSourceCreateWithURL`          | 只读取文件头，不加载像素数据                   |
| `kCGImageSourceImageRect`             | **核心**：指定归一化坐标裁剪区域，只解码该部分 |
| `kCGImageSourceThumbnailMaxPixelSize` | 限制单次解码的像素总数，防止内存暴涨           |
| `autoreleasepool`                     | 每次滚动都释放临时 `UIImage` 和 `CGImage`      |

### ⚠️ 注意事项
1. **PNG 格式**：如果原图是 PNG，解码时会占用更大内存，建议设置 `kCGImageSourceShouldCacheImmediately: false`。
2. **缓存策略**：上述代码每次滚动都重新解码，实际项目中应加入 **NSCache** 缓存已加载的 Tile。
3. **坐标系转换**：`kCGImageSourceImageRect` 使用**归一化坐标**，务必除以原始宽高，否则裁剪区域会偏移。

## 分片加载优化

好，既然你需要**完整的缓存 + 多 Tile 拼接方案**，我给你一套可直接运行的**专业级分块加载引擎**，包含三级缓存（内存 → 磁盘 → 原始文件）和智能预加载。

## 完整源码：TileEngine（分块加载引擎）

```swift
import UIKit
import ImageIO

// MARK: - 核心配置
class TileConfig {
    static let shared = TileConfig()
    let tileSize: CGFloat = 512          // 每块大小（像素）
    let maxCacheCount: Int = 50          // 内存缓存最大数量
    let preloadRadius: Int = 1           // 预加载周围块数
}

// MARK: - 瓦片数据模型
struct Tile: Hashable {
    let x: Int
    let y: Int
    let level: Int                       // 缩放层级（0为原图）
    
    var rect: CGRect {
        let size = TileConfig.shared.tileSize * CGFloat(level == 0 ? 1 : 1 << level)
        return CGRect(x: CGFloat(x) * size,
                      y: CGFloat(y) * size,
                      width: size,
                      height: size)
    }
}

// MARK: - 主引擎
class TileEngine {
    private let imageSource: CGImageSource
    private let fullSize: CGSize
    private let fileURL: URL
    
    // 三级缓存
    private let memoryCache = NSCache<NSString, UIImage>()
    private let diskCacheURL: URL
    private let queue = OperationQueue()  // 解码队列
    
    // 正在加载的 Tile（防止重复请求）
    private var loadingTiles = Set<Tile>()
    private let lock = NSLock()
    
    // MARK: - 初始化
    init?(fileURL: URL) {
        guard let source = CGImageSourceCreateWithURL(fileURL as CFURL, nil) else {
            return nil
        }
        self.imageSource = source
        self.fileURL = fileURL
        
        // 获取原始尺寸
        guard let props = CGImageSourceCopyProperties(source, nil) as? [CFString: Any],
              let w = props[kCGImagePropertyPixelWidth] as? CGFloat,
              let h = props[kCGImagePropertyPixelHeight] as? CGFloat else {
            return nil
        }
        self.fullSize = CGSize(width: w, height: h)
        
        // 磁盘缓存目录
        let cacheDir = FileManager.default.temporaryDirectory
            .appendingPathComponent("TileCache")
        try? FileManager.default.createDirectory(at: cacheDir, withIntermediateDirectories: true)
        self.diskCacheURL = cacheDir
        
        // 配置缓存限制
        memoryCache.countLimit = TileConfig.shared.maxCacheCount
        queue.maxConcurrentOperationCount = 2
    }
    
    // MARK: - 公开接口：获取可见区域的所有 Tile
    func tilesForVisibleRect(_ rect: CGRect, level: Int = 0) -> [Tile] {
        let size = tileSize(for: level)
        let minX = Int(floor(rect.minX / size))
        let maxX = Int(floor((rect.maxX - 1) / size))
        let minY = Int(floor(rect.minY / size))
        let maxY = Int(floor((rect.maxY - 1) / size))
        
        var tiles: [Tile] = []
        for x in minX...maxX {
            for y in minY...maxY {
                let tile = Tile(x: x, y: y, level: level)
                if tile.rect.intersects(rect) {
                    tiles.append(tile)
                }
            }
        }
        return tiles
    }
    
    /// 异步加载 Tile（带预加载）
    func loadTile(_ tile: Tile, completion: @escaping (UIImage?) -> Void) {
        // 1. 检查内存缓存
        let cacheKey = cacheKey(for: tile)
        if let cached = memoryCache.object(forKey: cacheKey as NSString) {
            completion(cached)
            // 预加载周围 Tile
            preloadAround(tile)
            return
        }
        
        // 2. 检查是否已在加载中
        lock.lock()
        if loadingTiles.contains(tile) {
            lock.unlock()
            return
        }
        loadingTiles.insert(tile)
        lock.unlock()
        
        // 3. 异步解码
        queue.addOperation { [weak self] in
            guard let self = self else { return }
            
            // 尝试磁盘缓存
            let diskPath = self.diskPath(for: tile)
            var image: UIImage?
            
            if let data = try? Data(contentsOf: diskPath),
               let cachedImage = UIImage(data: data) {
                image = cachedImage
            } else {
                // 从原始文件解码
                image = self.decodeTile(tile)
                
                // 保存到磁盘
                if let img = image,
                   let data = img.jpegData(compressionQuality: 0.9) {
                    try? data.write(to: diskPath)
                }
            }
            
            // 存入内存缓存
            if let img = image {
                self.memoryCache.setObject(img, forKey: cacheKey as NSString)
            }
            
            // 移除加载标记
            self.lock.lock()
            self.loadingTiles.remove(tile)
            self.lock.unlock()
            
            DispatchQueue.main.async {
                completion(image)
            }
        }
    }
    
    // MARK: - 核心解码方法
    private func decodeTile(_ tile: Tile) -> UIImage? {
        let size = tileSize(for: tile.level)
        let tileRect = CGRect(x: CGFloat(tile.x) * size,
                              y: CGFloat(tile.y) * size,
                              width: size,
                              height: size)
        
        // 计算归一化坐标
        let normalizedRect = CGRect(
            x: tileRect.minX / fullSize.width,
            y: tileRect.minY / fullSize.height,
            width: min(tileRect.width, fullSize.width - tileRect.minX) / fullSize.width,
            height: min(tileRect.height, fullSize.height - tileRect.minY) / fullSize.height
        )
        
        // 如果 Tile 超出图片范围，返回 nil
        guard normalizedRect.width > 0, normalizedRect.height > 0 else { return nil }
        
        let options: [CFString: Any] = [
            kCGImageSourceCreateThumbnailFromImageIfAbsent: true,
            kCGImageSourceThumbnailMaxPixelSize: max(size, size),  // 限制解码尺寸
            kCGImageSourceCreateThumbnailWithTransform: true,
            kCGImageSourceImageRect: normalizedRect as CFRect,
            kCGImageSourceShouldCacheImmediately: false
        ]
        
        guard let cgImage = CGImageSourceCreateThumbnailAtIndex(imageSource, 0, options as CFDictionary) else {
            return nil
        }
        
        return UIImage(cgImage: cgImage)
    }
    
    // MARK: - 预加载策略
    private func preloadAround(_ tile: Tile) {
        let radius = TileConfig.shared.preloadRadius
        let size = tileSize(for: tile.level)
        
        for dx in -radius...radius {
            for dy in -radius...radius {
                guard dx != 0 || dy != 0 else { continue }
                
                let neighbor = Tile(
                    x: tile.x + dx,
                    y: tile.y + dy,
                    level: tile.level
                )
                
                // 只预加载在图片范围内的 Tile
                let maxX = Int(ceil(fullSize.width / size))
                let maxY = Int(ceil(fullSize.height / size))
                guard neighbor.x >= 0, neighbor.x < maxX,
                      neighbor.y >= 0, neighbor.y < maxY else { continue }
                
                // 异步预加载（不阻塞主流程）
                loadTile(neighbor) { _ in }
            }
        }
    }
    
    // MARK: - 辅助方法
    private func tileSize(for level: Int) -> CGFloat {
        let baseSize = TileConfig.shared.tileSize
        return level == 0 ? baseSize : baseSize * CGFloat(1 << level)
    }
    
    private func cacheKey(for tile: Tile) -> String {
        return "\(fileURL.lastPathComponent)_\(tile.level)_\(tile.x)_\(tile.y)"
    }
    
    private func diskPath(for tile: Tile) -> URL {
        return diskCacheURL.appendingPathComponent(cacheKey(for: tile) + ".jpg")
    }
    
    // MARK: - 清空缓存
    func clearCache() {
        memoryCache.removeAllObjects()
        try? FileManager.default.removeItem(at: diskCacheURL)
        try? FileManager.default.createDirectory(at: diskCacheURL, withIntermediateDirectories: true)
    }
}

// MARK: - 使用示例：集成到 ScrollView
class TileViewController: UIViewController, UIScrollViewDelegate {
    private let scrollView = UIScrollView()
    private let containerView = UIView()
    private var tileEngine: TileEngine?
    private var visibleTiles: [Tile: UIImageView] = [:]
    
    override func viewDidLoad() {
        super.viewDidLoad()
        setupScrollView()
        loadImage()
    }
    
    private func setupScrollView() {
        scrollView.delegate = self
        scrollView.minimumZoomScale = 0.1
        scrollView.maximumZoomScale = 1.0
        scrollView.showsVerticalScrollIndicator = true
        scrollView.showsHorizontalScrollIndicator = true
        view.addSubview(scrollView)
        scrollView.frame = view.bounds
        scrollView.addSubview(containerView)
    }
    
    private func loadImage() {
        let url = Bundle.main.url(forResource: "huge_image", withExtension: "jpg")!
        tileEngine = TileEngine(fileURL: url)
        
        guard let engine = tileEngine else { return }
        scrollView.contentSize = engine.fullSize
        containerView.frame = CGRect(origin: .zero, size: engine.fullSize)
        
        updateVisibleTiles()
    }
    
    func scrollViewDidScroll(_ scrollView: UIScrollView) {
        updateVisibleTiles()
    }
    
    func scrollViewDidZoom(_ scrollView: UIScrollView) {
        updateVisibleTiles()
    }
    
    private func updateVisibleTiles() {
        guard let engine = tileEngine else { return }
        
        let visibleRect = scrollView.bounds
        let zoomScale = scrollView.zoomScale
        let pixelRect = CGRect(
            x: visibleRect.minX / zoomScale,
            y: visibleRect.minY / zoomScale,
            width: visibleRect.width / zoomScale,
            height: visibleRect.height / zoomScale
        )
        
        // 获取当前可见 Tile
        let neededTiles = engine.tilesForVisibleRect(pixelRect)
        
        // 移除不可见的 TileView
        let currentKeys = Set(visibleTiles.keys)
        let neededSet = Set(neededTiles)
        for tile in currentKeys.subtracting(neededSet) {
            visibleTiles[tile]?.removeFromSuperview()
            visibleTiles.removeValue(forKey: tile)
        }
        
        // 加载并显示新的 Tile
        for tile in neededSet {
            if visibleTiles[tile] == nil {
                let imageView = UIImageView()
                imageView.frame = tile.rect
                imageView.contentMode = .scaleAspectFill
                imageView.backgroundColor = .lightGray
                containerView.addSubview(imageView)
                visibleTiles[tile] = imageView
                
                // 异步加载
                engine.loadTile(tile) { [weak self] image in
                    DispatchQueue.main.async {
                        imageView.image = image
                        imageView.backgroundColor = .clear
                    }
                }
            }
        }
    }
}
```

## 核心机制说明

| 功能         | 实现方式                                             |
| ------------ | ---------------------------------------------------- |
| **三级缓存** | 内存（NSCache）→ 磁盘（临时目录）→ 原始文件          |
| **预加载**   | 加载当前 Tile 时自动加载周围 1 圈（可配置）          |
| **防重复**   | `loadingTiles` Set 加锁，避免同一 Tile 多次解码      |
| **智能裁剪** | `kCGImageSourceImageRect` 归一化坐标，只解码需要部分 |
| **自动回收** | `UIScrollView` 滚动时动态移除不可见 TileView         |
| **缩放支持** | 预留 `level` 参数，可扩展多层级缩略图                |

## 性能优化建议

1. **调整 `maxConcurrentOperationCount`**：根据设备性能设为 1~3。
2. **磁盘缓存格式**：使用 `jpegData(compressionQuality: 0.85)` 平衡速度与大小。
3. **内存预警**：监听 `UIApplicationDidReceiveMemoryWarningNotification`，调用 `clearCache()`。
4. **渐进加载**：先显示低分辨率预览图（`loadPreview`），再加载高清 Tile。

## 图片解压缩以JPG为例

不用系统 API（`CGImageSource`、`UIImage` 等），那就得**自己解析图片格式**，直接操作像素数据。这属于底层图像处理，我给你一套**纯手动解析 JPEG + 像素提取**的实现思路和核心源码。

---

## 核心原理

JPEG 是压缩格式，无法直接读取像素。手动实现的完整流程：

1. **解析 JPEG 文件头** → 获取图像尺寸、量化表、霍夫曼表
2. **解码 MCU（最小编码单元）** → 哈夫曼解码 → 反量化 → IDCT 逆离散余弦变换
3. **提取目标区域的 YCbCr 数据** → 转为 RGB
4. **只解码需要的 MCU 块**（重点优化）

---

## 简化实现：解析 PPM 格式（未压缩）

如果真的不用系统 API，最实用的是**自己解析未压缩格式**（如 PPM），或**用第三方库**。下面给你一个**纯 Swift 手动解析 PPM** 并提取小块的示例：

```swift
import Foundation

// MARK: - 手动解析 PPM 图片
class ManualImageParser {
    
    /// 从 PPM 文件提取指定区域（纯手动，无系统图像 API）
    static func extractTile(from fileURL: URL, rect: CGRect) -> [UInt8]? {
        guard let data = try? Data(contentsOf: fileURL) else {
            print("文件读取失败")
            return nil
        }
        
        // 1. 解析 PPM 头
        var offset = 0
        guard let header = parsePPMHeader(data, offset: &offset) else {
            return nil
        }
        
        let width = header.width
        let height = header.height
        let maxVal = header.maxVal
        let bytesPerChannel = maxVal > 255 ? 2 : 1
        let bytesPerPixel = bytesPerChannel * 3
        
        // 2. 计算目标区域（确保不越界）
        let x = Int(rect.minX), y = Int(rect.minY)
        let w = Int(rect.width), h = Int(rect.height)
        guard x >= 0, y >= 0, x + w <= width, y + h <= height else {
            print("裁剪区域超出图片范围")
            return nil
        }
        
        // 3. 提取像素数据（跳过头部，直接从像素数据开始）
        let pixelDataStart = offset
        var extractedPixels: [UInt8] = []
        
        for row in y..<(y + h) {
            let rowStart = pixelDataStart + (row * width + x) * bytesPerPixel * 3
            let rowEnd = rowStart + w * bytesPerPixel * 3
            
            guard rowEnd <= data.count else { break }
            
            // 提取该行的目标区域
            let rowData = data[rowStart..<rowEnd]
            
            // 如果是 16-bit PPM，需要转换
            if bytesPerChannel == 2 {
                for i in stride(from: 0, to: rowData.count, by: 2) {
                    // 大端序转小端
                    let high = rowData[rowData.startIndex + i]
                    let low = rowData[rowData.startIndex + i + 1]
                    let value = UInt16(high) << 8 | UInt16(low)
                    // 缩放到 8-bit
                    extractedPixels.append(UInt8(value >> 8))
                }
            } else {
                // 8-bit PPM，直接复制
                extractedPixels.append(contentsOf: rowData)
            }
        }
        
        return extractedPixels
    }
    
    // MARK: - 解析 PPM 头部
    private static func parsePPMHeader(_ data: Data, offset: inout Int) -> (width: Int, height: Int, maxVal: Int)? {
        var lines: [String] = []
        var currentLine = ""
        var index = offset
        
        while index < data.count {
            let byte = data[index]
            index += 1
            
            if byte == 10 { // 换行符
                if !currentLine.isEmpty {
                    lines.append(currentLine)
                    currentLine = ""
                }
                if lines.count >= 3 { break }
            } else if byte == 35 { // # 注释
                // 跳过注释行
                while index < data.count && data[index] != 10 {
                    index += 1
                }
            } else if byte != 13 { // 忽略回车
                currentLine.append(Character(UnicodeScalar(byte)))
            }
        }
        
        guard lines.count >= 3 else { return nil }
        
        // PPM 格式：P6 (二进制) 或 P3 (ASCII)
        let magic = lines[0]
        guard magic == "P6" || magic == "P3" else {
            print("仅支持 PPM P6/P3 格式")
            return nil
        }
        
        let dimensions = lines[1].split(separator: " ")
        guard dimensions.count == 2,
              let width = Int(dimensions[0]),
              let height = Int(dimensions[1]) else {
            return nil
        }
        
        guard let maxVal = Int(lines[2]) else { return nil }
        
        offset = index // 更新偏移到像素数据开始
        return (width, height, maxVal)
    }
}

// MARK: - 使用示例
func testManualExtract() {
    // 先准备一个 PPM 文件（可以用 ffmpeg 转换：ffmpeg -i input.jpg output.ppm）
    let ppmURL = Bundle.main.url(forResource: "sample", withExtension: "ppm")!
    
    let cropRect = CGRect(x: 100, y: 50, width: 200, height: 150)
    if let pixels = ManualImageParser.extractTile(from: ppmURL, rect: cropRect) {
        print("提取成功，像素数：\(pixels.count)")
        print("前 10 个字节：\(pixels.prefix(10))")
        
        // 可以手动转换为 UIImage（但需要自己构建 CGContext）
        // 这里需要 RGB 数据，可以用 Core Graphics 的 CGBitmapContextCreate
    }
}
```

## 如果要真正解析 JPEG（不用系统 API）

JPEG 解码复杂度极高，**不建议纯手写**，但如果你坚持要纯手动，需要实现：

### 1. JPEG 解码核心步骤

```swift
// 伪代码示意
class ManualJPEGDecoder {
    func decodeJPEG(_ data: Data) -> [[UInt8]]? {
        // Step 1: 解析 SOI (0xFFD8)
        // Step 2: 解析 APP0 (JFIF 标识)
        // Step 3: 解析 DQT (量化表)
        // Step 4: 解析 SOF0 (图像尺寸、组件数)
        // Step 5: 解析 DHT (霍夫曼表)
        // Step 6: 解析 SOS (开始扫描)
        // Step 7: 解码 MCU 块：
        //   - 哈夫曼解码
        //   - 反量化
        //   - IDCT 逆变换
        //   - YCbCr → RGB 转换
        // Step 8: 重组图像
        return nil
    }
}
```

### 2. 最小化解码（只解目标区域）

如果只提取一小块，需要：
- 解析 JPEG 的 **MCU 排列**（通常是 8x8 块）
- 只解码 **目标区域覆盖的 MCU**
- 跳过其他 MCU 的字节（需要计算偏移）

## 推荐替代方案（不用系统 API 但现实可行）

| 方案             | 实现方式                     | 优点                      |
| ---------------- | ---------------------------- | ------------------------- |
| **第三方库**     | `libjpeg-turbo` + Swift 桥接 | 高性能，完整 JPEG 支持    |
| **PPM 中间格式** | 先转换再手动解析             | 纯 Swift 实现，无系统依赖 |
| **Metal 纹理**   | 使用 GPU 解码和采样          | 适合超大图实时预览        |

---

## 总结

- **非系统 API 实现**理论上可行，但 JPEG 解码代码量巨大（数千行）
- **实际项目**建议用 `libjpeg-turbo` 或 `ImageIO`（系统 API）
- 如果**必须脱离系统 API**（如跨平台或逆向），最务实的是：
  1. 用 `ffmpeg` 预处理成 PPM
  2. 用上述纯 Swift 代码提取区域
  3. 或者封装 `libjpeg` C 库
