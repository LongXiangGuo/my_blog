# iOS 通用转场动画 + 业务经典动画完整手册
分为两大块：**页面间转场动画（VC 切换）**、**页面内业务经典动画（组件/弹窗/列表/交互反馈）**，覆盖 UIKit 原生、自定义、主流业务场景（IM、资讯、商城、个人中心、弹窗、表单）。

## 一、页面转场动画（ViewController Transition）
### 1. 系统原生标准转场（present/push 自带，无需自定义）
#### 1.1 UINavigationController Push/Pop 导航栈转场
1. **默认右滑推入**（push）
    - 效果：新页面从屏幕右侧滑入，旧页面向左平移缩小、透明度降低；pop 反向滑回。
    - 适用：列表→详情、多级页面、App 主流程。
    - 底层：`CATransition` + UIKit 内置交互手势返回。
2. **横向侧滑返回手势**
    系统自带全屏/边缘侧滑 pop，几乎所有资讯、商城、IM 标配。

#### 1.2 Modal 弹窗系统转场（presentViewController）
1. **默认覆盖弹出（pageSheet / formSheet iOS13+）**
    - iPhone：底部上滑弹出半页；iPad：居中浮窗卡片。
    - 业务：筛选弹窗、设置、编辑页、分享面板。
2. **全屏向上滑入（fullScreen）**
    新页面从底部全屏滑入，替代导航栈，短视频、相机、直播常用。
3. **交叉淡入淡出 crossDissolve**
    页面整体透明度渐变切换，无位移，适合设置切换、主题切换、极简工具页。
4. **翻页 flipHorizontal / flipVertical**
    3D 翻转卡片，极少商用，仅工具类小众 App。
5. **波纹揭示 reveal**
    圆形波纹扩散打开页面，相机相册、扫码页常用。

### 2. 自定义交互式转场（UIViewControllerAnimatedTransitioning）
大厂业务通用自定义转场，全靠这套协议实现：
#### 2.1 图片联动转场（头条/小红书/朋友圈图集）
- 逻辑：列表缩略图 → 大图预览，两张视图做位置、尺寸、圆角、透明度联动动画；
- 手势支持：下滑拖拽关闭大图，回弹阻尼动画；
- 业务场景：商品图、帖子图片、聊天图片预览。

#### 2. 顶部导航栏联动转场（资讯详情、文章页）
列表滑动到详情，导航栏透明度、标题、背景渐变联动变化，滚动同步动画。

#### 2. 3D 缩放弹出（支付弹窗、授权弹窗）
页面底层缩小变暗，弹窗中心从小到大弹性弹出，业务：支付、实名认证、权限申请。

#### 2. 侧边抽屉转场（外卖侧边菜单、App 侧边栏）
主页面右移露出左侧菜单，支持拖拽手势呼出/关闭。

## 二、页面内通用基础动画（UIView 层动画，UIView.animate / CABasicAnimation）
### 1. 透明度淡入淡出 alpha
- 淡入：0 → 1；淡出：1 → 0
- 场景：加载占位、空状态、标签切换、弹窗遮罩、Toast。

### 2. 位移平移 position / frame
- 向上滑入：view.y = 屏幕底部 → 目标位置（弹窗、输入框、评论面板）
- 向下滑出：弹窗关闭动画
- 左右平移：Tab 切换、分类标签滑动

### 3. 缩放 transform.scale
- 弹性放大：0.8 → 1.0（按钮点击反馈、弹窗弹出、红点提示）
- 缩小消失：1 → 0（删除、关闭、弹窗消失）

### 4. 旋转 transform.rotation
- 加载菊花、下拉刷新箭头、切换图标、开关组件。

### 5. 圆角、边框、阴影渐变动画
用户选中态、输入框聚焦、卡片高亮、夜间模式切换。

### 6. 背景色渐变 backgroundColor
Tab 选中、标签切换、输入框提示、状态提示（成功绿/警告黄）。

## 三、各大业务线经典专属动画（IM、商城、短视频、资讯、工具）
# （一）IM 聊天类动画（微信/QQ/钉钉通用）
1. **消息气泡弹出动画**
    消息从侧边小幅平移+轻微弹性缩放淡入，区分我方/对方消息左右滑入。
2. **输入框弹出动画**
    底部评论框从屏幕底部上滑，遮罩同步淡入；下滑拖拽收起。
3. **表情面板切换**
    表情面板上下平移，Tab 分类左右滑动切换。
4. **语音条声波动画**
    CAShapeLayer 动态高低起伏波形，录音时持续帧动画。
5. **消息撤回/删除收缩动画**
    气泡缩小透明度归零向上消失。
6. **小红点未读数字跳动**
    弹性缩放跳动提示新消息。
7. **图片预览联动转场**
    聊天气泡图片放大全屏预览，下滑关闭。
8. **视频播放占位加载环形旋转动画**

# （二）电商商城类动画（淘宝/京东/拼多多）
1. **商品卡片入场瀑布流动画**
    列表 cell 从上至下依次延迟淡入+小幅下移，阶梯入场。
2. **加入购物车抛物线动画**
    商品缩略图沿贝塞尔曲线飞到底部购物车图标，图标轻微跳动；核心转化动画。
3. **弹窗弹性弹出（优惠券、限时秒杀）**
    中心弹性缩放弹出，遮罩变暗；关闭缩小消失。
4. **Tab 分类下划线滚动动画**
    底部指示器跟随分类标签平滑位移、宽度自适应。
5. **商品图片左右滑动轮播**
    UIScrollView 分页平移，指示器同步切换。
6. **下拉刷新弹簧动画**
    下拉释放弹簧回弹，加载菊花旋转。
7. **规格选择面板底部上滑**
    选择尺码、颜色弹窗，底部滑入，支持拖拽下滑关闭。
8. **结算按钮高亮渐变动画**
    选中商品后按钮从灰色渐变橙色，轻微放大。
9. **订单状态流转渐变**
    待付款→已发货→完成，进度条逐段填充动画。

# （三）资讯/短视频类（抖音、小红书、知乎、头条）
1. **全屏视频滑动切换（上下翻页）**
    UIScrollView 分页垂直滑动，页面间轻微缩放+透明度渐变区分层级。
2. **图集左右滑动联动大图转场**
    列表缩略图联动全屏看图，手势下滑关闭。
3. **关注按钮点击缩放填充动画**
    空心心→实心红心弹性缩放，跳动反馈。
4. **评论面板底部上滑**
    视频底部评论区拖拽弹出/收起。
5. **骨架屏加载动画（Shimmer 微光流动）**
    卡片加载前渐变微光扫描，资讯、商城首页标配。
6. **顶部导航栏滚动渐变**
    滚动时导航栏从透明→白色渐变，标题显隐联动。
7. **图文详情长图渐进加载淡入**

# （四）弹窗 & 全局通用反馈动画（所有 App 共用）
1. **Toast 提示**
    底部居中淡入，停留2s后淡出；成功打勾缩放动画、失败叉号动画。
2. **Loading 加载动画**
    - 环形旋转菊花：网络请求、图片加载；
    - 圆点跳动三球动画：弹窗加载；
    - 进度条填充：文件上传/下载。
3. **Alert 系统弹窗 / 自定义弹窗**
    中心弹性缩放弹出，背景遮罩同步淡入；点击空白缩小淡出。
4. **ActionSheet 底部菜单**
    从屏幕底部整体滑入，分段菜单依次延迟入场。
5. **授权、支付密码弹窗**
    数字输入框逐位填充圆点动画，输入完成按钮渐变高亮。

# （五）表单、工具、系统设置类动画
1. **输入框聚焦动画**
    底部边框变色上浮，提示文字缩小上浮。
2. **开关 UISwitch 滑动切换动画**
    底层系统自带，红绿底色平滑过渡。
3. **倒计时数字滚动动画（验证码）**
    数字渐变灰度，倒计时进度条匀速缩短。
4. **页面切换淡入淡出（设置、工具页）**
    无位移，纯透明度切换，简洁轻量化。
5. **夜间模式全局颜色渐变**
    页面所有文字、背景、图标同步渐变过渡，无生硬闪屏。

# （六）列表专属动画
1. **Cell 阶梯入场动画**
    页面加载时 cell 从上到下依次延迟淡入+下移，提升页面层次感。
2. **删除 cell 左滑收缩动画**
    左滑出现删除按钮，点击 cell 向左收缩淡出，列表自动上移填补空位。
3. **下拉刷新弹簧回弹动画**
    UIRefreshControl 原生弹簧阻尼动画。
4. **上拉加载更多淡入动画**
    底部加载视图淡入，菊花旋转。

## 四、动画底层实现分类（开发区分）
### 1. UIView 基础动画（简单位移、透明度、缩放）
`[UIView animateWithDuration:delay:options:animations:completion:]`
- 优点：简单、无需操作图层，业务快速实现；
- 局限：只能操作 UIView 可动画属性，不支持复杂帧动画、路径动画。

### 2. CoreAnimation 底层图层动画（CALayer）
`CABasicAnimation / CAKeyframeAnimation / CAAnimationGroup / CASpringAnimation`
适用：波形、抛物线、3D翻转、弹簧弹性、形状绘制、无限循环加载动画。

### 3. 交互式手势动画（UIPanGestureRecognizer + 动画进度控制）
看图下滑关闭、抽屉拖拽、评论面板拖拽，手势实时同步动画进度。

### 4. 自定义转场协议（页面切换高级动画）
`UIViewControllerAnimatedTransitioning`、`UIPercentDrivenInteractiveTransition`
实现图片联动、抽屉、弹窗自定义页面切换。

## 五、动画开发通用规范（大厂设计统一标准）
1. **基础时长标准**
    - 轻反馈动画：0.15~0.2s（按钮点击、缩放）
    - 弹窗/页面滑入：0.25~0.35s
    - 复杂转场、联动大图：0.35~0.45s
    - 弹簧动画阻尼 0.7~0.9，初始速度 0.8
2. **缓动函数统一**$$
    出场：ease-out（先快后慢）
    入场：ease-in-out
3. **性能约束**
    复杂列表动画开启 `layer.shouldRasterize = YES` 缓存图层；避免离屏渲染（阴影、圆角混合导致卡顿）；大图动画提前缩略处$$理。
4. **无障碍适配**
    开启减弱动态效果（设置-辅助功能）时，全部复杂动画降级为淡入淡出，移除位移、缩放、视差动画。
