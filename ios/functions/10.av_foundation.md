# AVFoundation 完全指南

## 一、AVFoundation 整体架构

### 1.1 在系统层级中的位置

AVFoundation 是 Apple 平台上处理基于时间的视听媒体的**高级框架**。它在整个 iOS/macOS 媒体技术栈中处于中间层：

| 层级       | 框架                                 | 职责                                         |
| ---------- | ------------------------------------ | -------------------------------------------- |
| 高层       | AVKit / UIKit                        | 即用型播放器 UI、系统相机控制器              |
| **中间层** | **AVFoundation**                     | **媒体播放、采集、编辑、处理**               |
| 底层       | Core Audio / Core Video / Core Media | 音频/视频底层数据处理、CMTime 等原始数据类型 |
| 硬件层     | 硬件编解码器、GPU                    | 硬件加速编解码与渲染                         |

Core Media 提供了 AVFoundation 所用的低层级数据类型和接口，包括基于 `CMTime` 的时基模型。Core Audio 提供音频录制/播放的底层支持，Core Video 提供视频帧的缓存和像素格式转换支持。

### 1.2 功能单元划分

AVFoundation 包含 100 多个类，可以按功能单元进行拆分理解：

1. **音频播放和录制**：`AVAudioPlayer`、`AVAudioRecorder`
2. **媒体检查**：`AVAsset`、`AVMetadataItem`
3. **视频播放**：`AVPlayer`、`AVPlayerItem`
4. **媒体采集**：`AVCaptureSession`
5. **媒体编辑**：`AVMutableComposition`
6. **媒体处理**：`AVAssetReader`、`AVAssetWriter`

> **最佳实践**：应使用可用的最高层级抽象。如果只是想播放视频，使用 AVKit 框架；如果只需最少格式控制来录制视频，使用 `UIImagePickerController`。


## 二、类图结构与核心类

### 2.1 核心类继承关系

```
AVAsset (抽象基类)
├── AVURLAsset          // 从 URL 加载媒体
├── AVComposition       // 媒体合成（不可变）
│   └── AVMutableComposition  // 可变的媒体合成
└── AVAssetTrack        // 单个轨道的表示
    └── AVMutableCompositionTrack

AVPlayerItem            // 资产的播放状态
├── AVPlayerItemTrack   // 单个轨道的播放状态
└── (被 AVPlayer 使用)

AVPlayer                // 播放控制器
└── AVQueuePlayer       // 队列播放

AVCaptureSession        // 采集会话
├── AVCaptureDeviceInput    // 输入（摄像头/麦克风）
└── AVCaptureOutput         // 输出（文件/预览/数据）
    ├── AVCaptureMovieFileOutput
    ├── AVCaptureVideoDataOutput
    └── AVCapturePhotoOutput
```

### 2.2 核心类详解

**AVAsset** — 框架的核心，是框架设计的出发点。它是**一个或多个媒体数据集合的聚合表示**，提供标题、时长、自然呈现尺寸等信息。`AVAsset` 不依赖特定数据格式，是其他资产类的超类。

**AVAssetTrack** — 资产中每一部分媒体数据属于统一类型，称为轨道（Track）。典型情况下一轨代表音频，另一轨代表视频。

**AVPlayerItem** — 将资产的**呈现状态**与资产本身分离。这允许你同时播放同一资产的两个不同片段，且可用不同分辨率渲染。

**AVCaptureSession** — 采集系统的中心协调者，管理输入与输出设备之间的数据流。


## 三、实现原理

### 3.1 异步加载机制

AVFoundation 的一个重要设计理念是：**初始化资产或轨道并不意味着它已准备好使用**。计算时长等信息可能需要时间（如 MP3 文件可能不包含摘要信息）。解决方案是通过 **Block 回调异步获取值**，而非阻塞当前线程。

所有遵循 `AVAsynchronousKeyValueLoading` 协议的类都支持这种异步加载模式。

### 3.2 多线程与性能优化

AVFoundation 高度依赖多线程机制，充分利用多核硬件优势，大量使用 **Block 和 GCD**。采集会话建议在专用串行 DispatchQueue 中配置，避免 UI 卡顿。

### 3.3 硬件加速

AVFoundation 为视频播放和捕获提供了**硬件加速机制**来优化整个流程。在视频编辑和播放过程中，还可以利用 Core Animation 添加动画标题和图片效果。


## 四、设计模式

### 4.1 面向轨道（Track-Based）设计

编辑系统的架构是**面向轨道的**，允许像非线性编辑软件（如 Final Cut Pro）一样灵活操作音视频片段。编辑流程为：

```
AVAsset → AVMutableComposition → AVMutableCompositionTrack 
→ [AVMutableVideoComposition] → AVAssetExportSession
```

### 4.2 会话（Session）模式

`AVCaptureSession` 作为所有采集活动的汇集点，协调输入和输出的数据流动。数据流向为：

```
设备 → 输入(Input) → Session → 输出(Output) → 处理/展示
```

### 4.3 协议驱动设计

AVFoundation 大量使用 Protocol 来定义可扩展的能力。例如 `AVVideoCompositing` 协议允许实现自定义视频合成器。

### 4.4 工厂与构建器模式

通过 `AVCaptureDeviceInput(device:)` 等工厂方法创建输入对象，通过 `AVMutableComposition` 的 `addMutableTrack` 方法构建轨道。

### 4.5 观察者模式

通过 KVO 观察 `AVPlayerItem` 的 `status`、`loadedTimeRanges` 等属性变化，实现播放状态监控。


## 五、工作流程

### 5.1 视频播放流程

```
1. 创建 AVURLAsset(url:)
2. 创建 AVPlayerItem(asset:)
3. 创建 AVPlayer(playerItem:)
4. 创建 AVPlayerLayer(player:)
5. 调用 player.play()
```

播放器将资产的呈现状态与资产本身分离，通过 `AVPlayerItem` 管理播放状态。

### 5.2 媒体采集流程

```
1. 创建 AVCaptureSession()
2. 获取 AVCaptureDevice（摄像头/麦克风）
3. 创建 AVCaptureDeviceInput
4. 创建 AVCaptureOutput（文件输出/数据输出/照片输出）
5. 添加输入和输出到 Session（先检查 canAddInput/Output）
6. 在专用队列调用 session.startRunning()
7. 处理输出回调或保存文件
```

`AVCaptureSession` 可同时管理多个输入输出（如前后摄像头切换、同时采集视频与音频）。

### 5.3 媒体编辑流程

```
1. 创建 AVMutableComposition()
2. 添加可变轨道 (addMutableTrack)
3. 从 AVAsset 获取 AVAssetTrack
4. 将片段插入轨道 (insertTimeRange:of:at:)
5. [可选] 配置 AVMutableVideoComposition（转场/水印）
6. 创建 AVAssetExportSession 导出
```

编辑操作归根结底都是：把多个 AVAsset 的音视频轨道插入到 `AVMutableComposition` 对应轨道中。


## 六、具体用法与使用场景

### 6.1 场景一：视频播放

```swift
import AVFoundation
import AVKit

class VideoPlayerViewController: UIViewController {
    var player: AVPlayer?
    var playerLayer: AVPlayerLayer?
    
    override func viewDidLoad() {
        super.viewDidLoad()
        
        guard let url = Bundle.main.url(forResource: "sample", withExtension: "mp4") else {
            return
        }
        
        let asset = AVURLAsset(url: url)
        let playerItem = AVPlayerItem(asset: asset)
        player = AVPlayer(playerItem: playerItem)
        
        playerLayer = AVPlayerLayer(player: player)
        playerLayer?.frame = view.bounds
        playerLayer?.videoGravity = .resizeAspect
        view.layer.addSublayer(playerLayer!)
        
        // 观察播放状态
        playerItem.addObserver(self, forKeyPath: #keyPath(AVPlayerItem.status), 
                               options: [.new, .initial], context: nil)
    }
    
    override func observeValue(forKeyPath keyPath: String?, of object: Any?, 
                               change: [NSKeyValueChangeKey : Any]?, context: UnsafeMutableRawPointer?) {
        if keyPath == #keyPath(AVPlayerItem.status) {
            if let item = object as? AVPlayerItem, item.status == .readyToPlay {
                player?.play()
            }
        }
    }
}
```

### 6.2 场景二：视频采集与录制

```swift
import AVFoundation

class CameraController: NSObject {
    private let session = AVCaptureSession()
    private var movieOutput = AVCaptureMovieFileOutput()
    private var previewLayer: AVCaptureVideoPreviewLayer?
    
    func setupCamera() throws {
        // 1. 配置 session
        session.sessionPreset = .high
        
        // 2. 获取摄像头
        guard let camera = AVCaptureDevice.default(.builtInWideAngleCamera, 
                                                   for: .video, 
                                                   position: .back) else {
            throw NSError(domain: "Camera", code: -1)
        }
        
        // 3. 创建输入
        let cameraInput = try AVCaptureDeviceInput(device: camera)
        if session.canAddInput(cameraInput) {
            session.addInput(cameraInput)
        }
        
        // 4. 创建音频输入
        guard let microphone = AVCaptureDevice.default(for: .audio) else {
            throw NSError(domain: "Microphone", code: -2)
        }
        let audioInput = try AVCaptureDeviceInput(device: microphone)
        if session.canAddInput(audioInput) {
            session.addInput(audioInput)
        }
        
        // 5. 创建输出
        if session.canAddOutput(movieOutput) {
            session.addOutput(movieOutput)
        }
        
        // 6. 预览层
        previewLayer = AVCaptureVideoPreviewLayer(session: session)
        previewLayer?.videoGravity = .resizeAspectFill
    }
    
    func startRecording(to url: URL) {
        guard movieOutput.isRecording == false else { return }
        movieOutput.startRecording(to: url, recordingDelegate: self)
    }
    
    func stopRecording() {
        guard movieOutput.isRecording else { return }
        movieOutput.stopRecording()
    }
    
    func startSession() {
        DispatchQueue.global(qos: .userInitiated).async {
            self.session.startRunning()
        }
    }
}

extension CameraController: AVCaptureFileOutputRecordingDelegate {
    func fileOutput(_ output: AVCaptureFileOutput, 
                    didFinishRecordingTo outputFileURL: URL, 
                    from connections: [AVCaptureConnection], 
                    error: Error?) {
        // 处理录制完成
    }
}
```

### 6.3 场景三：视频剪辑与合成

```swift
import AVFoundation

func mergeVideos(videoURLs: [URL], outputURL: URL, completion: @escaping (Bool, Error?) -> Void) {
    let composition = AVMutableComposition()
    
    guard let videoTrack = composition.addMutableTrack(withMediaType: .video, 
                                                        preferredTrackID: kCMPersistentTrackID_Invalid),
          let audioTrack = composition.addMutableTrack(withMediaType: .audio, 
                                                        preferredTrackID: kCMPersistentTrackID_Invalid) else {
        completion(false, nil)
        return
    }
    
    var currentTime = CMTime.zero
    
    for url in videoURLs {
        let asset = AVURLAsset(url: url)
        guard let assetVideoTrack = asset.tracks(withMediaType: .video).first,
              let assetAudioTrack = asset.tracks(withMediaType: .audio).first else {
            continue
        }
        
        let duration = asset.duration
        try? videoTrack.insertTimeRange(CMTimeRangeMake(start: .zero, duration: duration),
                                        of: assetVideoTrack,
                                        at: currentTime)
        try? audioTrack.insertTimeRange(CMTimeRangeMake(start: .zero, duration: duration),
                                        of: assetAudioTrack,
                                        at: currentTime)
        currentTime = CMTimeAdd(currentTime, duration)
    }
    
    guard let exportSession = AVAssetExportSession(asset: composition, 
                                                   presetName: AVAssetExportPresetHighestQuality) else {
        completion(false, nil)
        return
    }
    
    exportSession.outputURL = outputURL
    exportSession.outputFileType = .mp4
    exportSession.shouldOptimizeForNetworkUse = true
    
    exportSession.exportAsynchronously {
        DispatchQueue.main.async {
            completion(exportSession.status == .completed, exportSession.error)
        }
    }
}
```

### 6.4 场景四：生成视频缩略图

```swift
func generateThumbnail(from url: URL, at time: CMTime) -> UIImage? {
    let asset = AVURLAsset(url: url)
    let generator = AVAssetImageGenerator(asset: asset)
    generator.appliesPreferredTrackTransform = true
    
    do {
        let cgImage = try generator.copyCGImage(at: time, actualTime: nil)
        return UIImage(cgImage: cgImage)
    } catch {
        print("生成缩略图失败: \(error)")
        return nil
    }
}
```

## 八、常见坑与避坑指南

### 8.1 权限相关

**坑**：录制或采集时 `record()` 返回 false 或采集失败。

**解决**：
- 在 Info.plist 中添加 `NSCameraUsageDescription` 和 `NSMicrophoneUsageDescription`
- 使用 `AVCaptureDevice.requestAccess(for:)` 请求权限
- 检查 `AVAuthorizationStatus` 状态

### 8.2 Session 配置

**坑**：在非专用队列配置 Session 导致 UI 卡顿。

**解决**：在专用串行 DispatchQueue 中配置和启动 Session：
```swift
let sessionQueue = DispatchQueue(label: "session queue", qos: .userInitiated)
sessionQueue.async {
    self.session.startRunning()
}
```

### 8.3 轨道时间对齐

**坑**：轨道片段未对齐，导致黑帧或画面错乱。

**解决**：注意 `CMTime` 的精度问题，使用 `CMTimeMake` 时注意分母的选择。视频合成中不要在各片段间留空隙。

### 8.4 播放器内存问题

**坑**：播放远程媒体时，把整个文件先下载到内存再交给播放器，导致内存暴涨甚至 App 被杀。

**解决**：使用 `AVPlayer` 直接播放 URL，它支持流式播放和 HLS。

### 8.5 轨道数量过多

**坑**：使用过多 `AVMutableCompositionTrack` 导致播放失败。

**解决**：避免为每个视频片段创建单独的轨道，尽量复用轨道，或限制同时使用的轨道数量。

### 8.6 视频合成中的静态帧问题

**坑**：将 `AVMutableVideoComposition.frameDuration` 设置为资产的总时长，导致只产生一帧然后被"保持"。

**解决**：`frameDuration` 应设置为每帧的持续时间（如 1/30 秒），而非总时长。

### 8.7 导出失败

**坑**：`AVAssetExportSession` 导出失败，错误码 -11800 等。

**解决**：
- 检查输出路径是否有写入权限
- 确保 `outputFileType` 与预设匹配
- 检查资产是否可导出 (`asset.isExportable`)

### 8.8 API 废弃

**坑**：iOS 26 后部分 API 被废弃。

**解决**：
- 在 Xcode Build Settings 中启用 Deprecated Functions 警告
- 关注 WWDC 的 AVFoundation 更新

### 8.9 录制视频开头黑帧

**坑**：录制视频开头或结尾出现黑帧。

**解决**：在用户按下录制按钮之前就配置好 `AVCaptureMovieFileOutput`，而不是按下时才配置。

### 8.10 委托方法未被调用

**坑**：`AVContentKeySessionDelegate` 等方法未被调用。

**解决**：
- 确认代理已设置并实现了必要的方法
- 检查会话状态和密钥请求流程是否正确启动
- 查看控制台输出获取错误信息


## 九、调试建议

Apple 官方提供了技术笔记 TN2447 专门讨论 AVFoundation 合成、视频合成和音频混合的调试：

1. **可视化 Composition**：将合成内容可视化输出，检查轨道对齐情况
2. **检查轨道段对齐**：确保所有轨道段在时间轴上正确对齐
3. **检查图层变换**：变换矩阵错误可能导致内容超出边界
4. **使用断言**：在关键位置添加断言验证状态
5. **日志输出**：打印 `CMTime`、轨道 ID 等关键信息
