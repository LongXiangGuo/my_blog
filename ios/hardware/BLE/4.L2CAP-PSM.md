# L2CAP PSM
## 1. 基本定义
**PSM：Protocol/Service Multiplexer，协议/服务多路复用器**
作用：在**经典蓝牙 BR/EDR** 中，用于 L2CAP 面向连接信道建立阶段，标识目标上层服务/协议。

> 等价类比：TCP 端口号

## 2. 核心特性
1. **生命周期约束**
    PSM **仅出现在 `L2CAP_ConnectReq` 连接请求报文**。
    信道协商完成、通道建立成功后，后续所有L2CAP业务数据包不再携带PSM。
2. **功能边界区分（PSM vs CID）**
    | 标识 | 使用阶段       | 作用                                           |
    | ---- | -------------- | ---------------------------------------------- |
    | PSM  | 信道建立阶段   | 定位远端服务类型，用于发起连接                 |
    | CID  | 信道全生命周期 | 区分同一条ACL链路上多条独立L2CAP信道，数据路由 |
    > 总结：建通道查PSM，传数据用CID。

## 3. 工作时序流程
1. 服务端预先向L2CAP注册指定PSM，对外暴露服务；
2. 客户端发送 `L2CAP_ConnectReq`，携带目标PSM与本方源CID（SCID）；
3. 对端检索本机已注册PSM列表：
    - 存在对应服务：分配目的CID（DCID），回复 `L2CAP_ConnectRsp`，信道建立；
    - 无对应服务：返回连接拒绝；
4. 信道就绪，双向业务传输仅依靠 SCID / DCID 路由，PSM不再参与。

```
Client                            Server
   |                                |
   |       注册监听 PSM=N           |<-- 预注册
   |                                |
   | L2CAP_ConnectReq(PSM=N, SCID) |
   |------------------------------->|
   |                                | 查询PSM注册表
   | L2CAP_ConnectRsp(DCID)         |
   |<-------------------------------|
   |                                |
   |    L2CAP Data (SCID, DCID)     |
   |<------------------------------>| 持续业务通信
```

## 4. 经典蓝牙 PSM 规范约束
1. 合法PSM取值**必须为奇数**；
2. 取值区间划分
    - `0x0001 ~ 0x0EFF`：蓝牙SIG标准协议预留；
    - `≥ 0x1001`：厂商自定义私有服务（只能使用奇数）。

### 标准常用PSM清单
| PSM    | 对应协议     |
| ------ | ------------ |
| 0x0001 | SDP          |
| 0x0003 | RFCOMM       |
| 0x0011 | HID Control  |
| 0x0013 | HID Data     |
| 0x0017 | AVCTP(AVRCP) |
| 0x0019 | AVDTP(A2DP)  |

## 5. PSM / SPSM 区分（BR/EDR vs BLE）
1. **BR/EDR（经典蓝牙）**
    使用 **PSM**，用于传统面向连接L2CAP信道。
2. **BLE**
    - 基础ATT/GATT通道：固定CID=0x0004，**不需要SPSM**；
    - LE Credit-Based CoC（信用基面向连接通道）：使用 **SPSM（LE_PSM）**；
    - SPSM逻辑与PSM一致，但报文格式、取值范围独立，不可混用。
> 行业口语常将SPSM简称为PSM，正式文档需严格区分。

## 6. 关键结论
1. PSM 是**服务标识**，CID 是**信道实例标识**；
2. PSM 仅用于握手建链，数据传输阶段完全依赖CID；
3. 经典蓝牙PSM强制奇数，自定义业务必须选用 `0x1001` 及以上奇数；
4. BLE CoC 使用SPSM，不能直接复用经典蓝牙PSM规则。
