# iOS异常处理

异常捕捉整体思路,实现代码示例子,以及常见异常分析

## 🏗️ 架构设计

### 三层异常捕获架构

```
┌─────────────────────────────────────────────────────────────┐
│                     应用层（Application）                    │
├─────────────────────────────────────────────────────────────┤
│                    崩溃收集框架（CrashCollector）            │
├──────────────────┬──────────────────┬─────────────────────┤
│   NSException    │   Signal        │   Mach Exception    │
│   (OC层异常)     │   (Unix信号)    │   (内核异常)        │
├──────────────────┴──────────────────┴─────────────────────┤
│                   底层（Mach Kernel）                      │
└─────────────────────────────────────────────────────────────┘
```

### 核心模块说明

| 模块                  | 职责                                 | 关键实现                                       |
| --------------------- | ------------------------------------ | ---------------------------------------------- |
| **Exception Handler** | 捕获 OC 层的 `@throw` 异常           | `NSSetUncaughtExceptionHandler`                |
| **Signal Handler**    | 捕获 Unix 信号（段错误、非法指令等） | `signal()` 系统调用                            |
| **Mach Handler**      | 捕获内核级异常（权限最高）           | `task_set_exception_ports` + `mach_msg_server` |
| **Report Manager**    | 持久化存储崩溃日志                   | JSON 序列化 + 文件存储                         |
| **Upload Manager**    | 异步上报崩溃日志                     | 后台队列 + 网络请求                            |
| **Alert Manager**     | 用户交互回调                         | Block 回调 + 主线程 UI                         |

## 🔐 高可靠性保障机制

### 1. 防递归崩溃
```objective-c
// 使用原子操作防止重复处理崩溃
if (OSAtomicTestAndSet(7, &g_isHandlingCrash)) {
    return;  // 已经在处理崩溃，直接返回
}
```

### 2. 线程安全
```objective-c
// 使用 OSSpinLock 保护共享数据
OSSpinLockLock(&g_reportLock);
// ... 操作 g_pendingReports
OSSpinLockUnlock(&g_reportLock);
```

### 3. 崩溃日志持久化
- 崩溃发生时立即写入磁盘，防止内存中的数据在重启后丢失
- 使用 JSON 格式便于解析和上传
- 存储在 Document 目录，避免被系统清理

### 4. 三层异常捕获保底
- **Mach 异常**（最高优先级）：捕获内核级异常
- **Signal**（中间层）：捕获 Unix 信号
- **NSException**（最后一道防线）：捕获 OC 异常

### 5. 异常恢复机制
```objective-c
// 保存原有 Handler，在崩溃处理后恢复
g_previousExceptionHandler = NSGetUncaughtExceptionHandler();
NSSetUncaughtExceptionHandler(&uncaughtExceptionHandler);

// 崩溃处理完成后恢复默认行为
signal(signal, SIG_DFL);
raise(signal);
```

## 📊 使用示例

```objective-c
// AppDelegate.m
- (BOOL)application:(UIApplication *)application 
didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    
    CrashCollector *collector = [CrashCollector sharedInstance];
    
    // 设置上报回调
    collector.reportBlock = ^(NSDictionary *crashInfo) {
        // 上报到你的服务器
        [[NetworkManager shared] uploadCrash:crashInfo completion:nil];
    };
    
    // 设置 Alert 回调
    collector.alertBlock = ^(NSDictionary *crashInfo, void(^continueHandler)(BOOL)) {
        // 显示友好的崩溃提示
        UIAlertController *alert = [UIAlertController 
            alertControllerWithTitle:@"App发生异常"
            message:@"是否继续使用？"
            preferredStyle:UIAlertControllerStyleAlert];
        
        [alert addAction:[UIAlertAction actionWithTitle:@"退出" 
                                                  style:UIAlertActionStyleDestructive 
                                                handler:^(UIAlertAction *action) {
            continueHandler(NO);  // 退出应用
        }]];
        
        [alert addAction:[UIAlertAction actionWithTitle:@"继续" 
                                                  style:UIAlertActionStyleDefault 
                                                handler:^(UIAlertAction *action) {
            continueHandler(YES); // 继续运行
        }]];
        
        [[UIApplication sharedApplication].keyWindow.rootViewController 
            presentViewController:alert animated:YES completion:nil];
    };
    
    // 启动收集
    [collector startCollecting];
    
    return YES;
}
```

## 📦 完整实现代码

```objective-c
// CrashCollector.h
#import <Foundation/Foundation.h>

typedef NS_ENUM(NSInteger, CrashType) {
    CrashTypeNSException = 0,
    CrashTypeSignal,
    CrashTypeMachException
};

typedef void(^CrashReportBlock)(NSDictionary *crashInfo);
typedef void(^CrashAlertBlock)(NSDictionary *crashInfo, void(^continueHandler)(BOOL));

@interface CrashCollector : NSObject

@property (nonatomic, copy) CrashReportBlock reportBlock;
@property (nonatomic, copy) CrashAlertBlock alertBlock;
@property (nonatomic, assign) BOOL isCollecting;

+ (instancetype)sharedInstance;
- (void)startCollecting;
- (void)stopCollecting;
- (void)saveCrashReport:(NSDictionary *)report;
- (void)uploadPendingReports;

@end
```

```objective-c
// CrashCollector.m
#import "CrashCollector.h"
#import <mach/mach.h>
#import <mach/mach_init.h>
#import <mach/mach_port.h>
#import <mach/mach_error.h>
#import <pthread.h>
#import <execinfo.h>
#import <libkern/OSAtomic.h>

// ========== 异常处理器结构体 ==========
typedef struct {
    unsigned int exceptionCode;
    unsigned int exceptionSubcode;
    void *exceptionAddress;
    uintptr_t threadContext[128];
} CrashContext;

// ========== 全局变量 ==========
static CrashCollector *g_sharedInstance = nil;
static mach_port_t g_exceptionPort = MACH_PORT_NULL;
static BOOL g_isHandlingCrash = NO;
static NSUncaughtExceptionHandler *g_previousExceptionHandler = NULL;
static NSMutableDictionary *g_pendingReports = nil;
static pthread_mutex_t g_crashMutex = PTHREAD_MUTEX_INITIALIZER;
static OSSpinLock g_reportLock = OS_SPINLOCK_INIT;

// ========== 前向声明 ==========
static void uncaughtExceptionHandler(NSException *exception);
static void signalHandler(int signal);
static kern_return_t catchMachException(mach_port_t exceptionPort, 
                                        exception_type_t exceptionType, 
                                        mach_exception_data_t code, 
                                        mach_msg_type_number_t codeCount);
static void handleCrash(CrashContext *context, CrashType type);

// ========== 信号列表 ==========
static const int kSignals[] = {
    SIGABRT,  // 中止程序
    SIGILL,   // 非法指令
    SIGSEGV,  // 段错误（访问无效内存）
    SIGFPE,   // 浮点异常
    SIGBUS,   // 总线错误
    SIGPIPE,  // 管道破裂
    SIGTRAP   // 断点/陷阱
};
static const int kSignalCount = sizeof(kSignals) / sizeof(kSignals[0]);

// ========== 实现 ==========
@implementation CrashCollector

#pragma mark - Singleton

+ (instancetype)sharedInstance {
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        g_sharedInstance = [[CrashCollector alloc] init];
        g_pendingReports = [NSMutableDictionary dictionary];
    });
    return g_sharedInstance;
}

- (instancetype)init {
    self = [super init];
    if (self) {
        _isCollecting = NO;
        pthread_mutex_init(&g_crashMutex, NULL);
    }
    return self;
}

- (void)dealloc {
    [self stopCollecting];
    pthread_mutex_destroy(&g_crashMutex);
}

#pragma mark - Public Methods

- (void)startCollecting {
    if (self.isCollecting) return;
    
    pthread_mutex_lock(&g_crashMutex);
    
    // 1. 初始化Mach异常端口
    [self setupMachExceptionPort];
    
    // 2. 注册NSException Handler
    [self setupExceptionHandler];
    
    // 3. 注册Signal Handler
    [self setupSignalHandlers];
    
    self.isCollecting = YES;
    
    pthread_mutex_unlock(&g_crashMutex);
    
    // 4. 启动后检查是否有未上报的崩溃
    [self uploadPendingReports];
}

- (void)stopCollecting {
    if (!self.isCollecting) return;
    
    pthread_mutex_lock(&g_crashMutex);
    
    // 恢复异常端口
    if (g_exceptionPort != MACH_PORT_NULL) {
        mach_port_destroy(mach_task_self(), g_exceptionPort);
        g_exceptionPort = MACH_PORT_NULL;
    }
    
    // 恢复NSException Handler
    NSSetUncaughtExceptionHandler(g_previousExceptionHandler);
    
    // 恢复Signal Handlers
    for (int i = 0; i < kSignalCount; i++) {
        signal(kSignals[i], SIG_DFL);
    }
    
    self.isCollecting = NO;
    
    pthread_mutex_unlock(&g_crashMutex);
}

- (void)saveCrashReport:(NSDictionary *)report {
    OSSpinLockLock(&g_reportLock);
    
    NSString *reportId = [[NSUUID UUID] UUIDString];
    NSString *filePath = [self reportFilePath:reportId];
    NSData *jsonData = [NSJSONSerialization dataWithJSONObject:report 
                                                       options:NSJSONWritingPrettyPrinted 
                                                         error:nil];
    [jsonData writeToFile:filePath atomically:YES];
    
    // 记录待上报
    g_pendingReports[reportId] = @{
        @"path": filePath,
        @"timestamp": @([[NSDate date] timeIntervalSince1970])
    };
    
    OSSpinLockUnlock(&g_reportLock);
}

- (void)uploadPendingReports {
    dispatch_async(dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_HIGH, 0), ^{
        OSSpinLockLock(&g_reportLock);
        NSArray *reportIds = [g_pendingReports allKeys];
        OSSpinLockUnlock(&g_reportLock);
        
        for (NSString *reportId in reportIds) {
            OSSpinLockLock(&g_reportLock);
            NSDictionary *info = g_pendingReports[reportId];
            NSString *filePath = info[@"path"];
            OSSpinLockUnlock(&g_reportLock);
            
            if (filePath && [[NSFileManager defaultManager] fileExistsAtPath:filePath]) {
                NSData *data = [NSData dataWithContentsOfFile:filePath];
                if (data) {
                    NSDictionary *report = [NSJSONSerialization JSONObjectWithData:data 
                                                                           options:0 
                                                                             error:nil];
                    if (self.reportBlock && report) {
                        self.reportBlock(report);
                    }
                    
                    // 上报成功后删除本地文件
                    [[NSFileManager defaultManager] removeItemAtPath:filePath error:nil];
                    
                    OSSpinLockLock(&g_reportLock);
                    [g_pendingReports removeObjectForKey:reportId];
                    OSSpinLockUnlock(&g_reportLock);
                }
            }
        }
    });
}

#pragma mark - Setup Handlers

- (void)setupMachExceptionPort {
    // 创建异常端口
    kern_return_t kr = mach_port_allocate(mach_task_self(), 
                                          MACH_PORT_RIGHT_RECEIVE, 
                                          &g_exceptionPort);
    if (kr != KERN_SUCCESS) {
        NSLog(@"Failed to allocate mach port: %s", mach_error_string(kr));
        return;
    }
    
    // 设置端口权限
    kr = mach_port_insert_right(mach_task_self(), 
                                g_exceptionPort, 
                                g_exceptionPort, 
                                MACH_MSG_TYPE_MAKE_SEND);
    if (kr != KERN_SUCCESS) {
        NSLog(@"Failed to insert right: %s", mach_error_string(kr));
        mach_port_destroy(mach_task_self(), g_exceptionPort);
        g_exceptionPort = MACH_PORT_NULL;
        return;
    }
    
    // 注册为异常端口
    kr = task_set_exception_ports(mach_task_self(),
                                  EXC_MASK_BAD_ACCESS |
                                  EXC_MASK_BAD_INSTRUCTION |
                                  EXC_MASK_ARITHMETIC |
                                  EXC_MASK_SOFTWARE |
                                  EXC_MASK_BREAKPOINT |
                                  EXC_MASK_EMULATION |
                                  EXC_MASK_SYSCALL |
                                  EXC_MASK_MACH_SYSCALL |
                                  EXC_MASK_RPC_ALERT |
                                  EXC_MASK_CRASH |
                                  EXC_MASK_GUARD |
                                  EXC_MASK_CORPSE_NOTIFY,
                                  g_exceptionPort,
                                  EXCEPTION_DEFAULT | MACH_EXCEPTION_CODES,
                                  THREAD_STATE_NONE);
    if (kr != KERN_SUCCESS) {
        NSLog(@"Failed to set exception port: %s", mach_error_string(kr));
        mach_port_destroy(mach_task_self(), g_exceptionPort);
        g_exceptionPort = MACH_PORT_NULL;
        return;
    }
    
    // 启动异常处理线程
    [NSThread detachNewThreadSelector:@selector(machExceptionThread) 
                             toTarget:self 
                           withObject:nil];
}

- (void)setupExceptionHandler {
    g_previousExceptionHandler = NSGetUncaughtExceptionHandler();
    NSSetUncaughtExceptionHandler(&uncaughtExceptionHandler);
}

- (void)setupSignalHandlers {
    for (int i = 0; i < kSignalCount; i++) {
        signal(kSignals[i], &signalHandler);
    }
}

#pragma mark - Mach Exception Thread

- (void)machExceptionThread {
    @autoreleasepool {
        // 设置线程名称便于调试
        [[NSThread currentThread] setName:@"CrashCollector-MachThread"];
        
        // 创建消息接收buffer
        mach_msg_server_t server = (mach_msg_server_t)&mach_exception_handler_server;
        kern_return_t kr = mach_msg_server(server,
                                           sizeof(mach_msg_base_t) + sizeof(mach_msg_port_descriptor_t) + 1024,
                                           g_exceptionPort,
                                           MACH_MSG_TIMEOUT_NONE);
        if (kr != KERN_SUCCESS) {
            NSLog(@"Mach message server failed: %s", mach_error_string(kr));
        }
    }
}

// Mach异常处理服务器回调
kern_return_t catchMachException(mach_port_t exceptionPort,
                                  exception_type_t exceptionType,
                                  mach_exception_data_t code,
                                  mach_msg_type_number_t codeCount) {
    
    // 防止重复处理
    if (OSAtomicTestAndSet(7, &g_isHandlingCrash)) {
        return KERN_FAILURE;
    }
    
    // 构建上下文
    CrashContext context = {0};
    context.exceptionCode = code[0];
    if (codeCount > 1) {
        context.exceptionSubcode = code[1];
    }
    context.exceptionAddress = (void *)code[0]; // 简化处理
    
    // 获取线程状态
    thread_t thread = mach_thread_self();
    thread_state_flavor_t flavor = x86_THREAD_STATE;
    mach_msg_type_number_t stateCount = x86_THREAD_STATE_COUNT;
    x86_thread_state_t state;
    
    kern_return_t kr = thread_get_state(thread, 
                                        flavor, 
                                        (thread_state_t)&state, 
                                        &stateCount);
    if (kr == KERN_SUCCESS) {
        // 保存线程上下文（简化示例）
        memcpy(context.threadContext, &state, sizeof(state));
    }
    
    // 处理崩溃
    handleCrash(&context, CrashTypeMachException);
    
    // 继续原有异常处理流程
    task_set_exception_ports(mach_task_self(),
                             EXC_MASK_ALL,
                             MACH_PORT_NULL,
                             EXCEPTION_DEFAULT,
                             THREAD_STATE_NONE);
    
    return KERN_FAILURE;
}

#pragma mark - Crash Handlers

static void uncaughtExceptionHandler(NSException *exception) {
    // 防止递归
    if (OSAtomicTestAndSet(7, &g_isHandlingCrash)) {
        return;
    }
    
    CrashContext context = {0};
    context.exceptionAddress = (void *)[exception callStackReturnAddresses].firstObject;
    
    // 收集堆栈
    NSArray *callStack = [exception callStackSymbols];
    
    // 构建崩溃报告
    NSMutableDictionary *report = [NSMutableDictionary dictionary];
    report[@"type"] = @(CrashTypeNSException);
    report[@"name"] = exception.name;
    report[@"reason"] = exception.reason;
    report[@"stack"] = callStack;
    report[@"timestamp"] = @([[NSDate date] timeIntervalSince1970]);
    report[@"appVersion"] = [[NSBundle mainBundle] objectForInfoDictionaryKey:@"CFBundleShortVersionString"];
    report[@"systemVersion"] = [[UIDevice currentDevice] systemVersion];
    report[@"deviceModel"] = [self deviceModel];
    
    // 保存报告
    [[CrashCollector sharedInstance] saveCrashReport:report];
    
    // 显示Alert（如果设置了回调）
    [self showCrashAlert:report];
    
    // 调用原有的异常处理器
    if (g_previousExceptionHandler) {
        g_previousExceptionHandler(exception);
    }
    
    // 清理资源
    OSAtomicTestAndClear(7, &g_isHandlingCrash);
}

static void signalHandler(int signal) {
    if (OSAtomicTestAndSet(7, &g_isHandlingCrash)) {
        return;
    }
    
    CrashContext context = {0};
    context.exceptionCode = signal;
    context.exceptionAddress = (void *)_NSGetMachExecuteHeader();
    
    // 获取堆栈
    void *backtraceFrames[128];
    int frameCount = backtrace(backtraceFrames, 128);
    NSMutableArray *stackSymbols = [NSMutableArray array];
    char **symbols = backtrace_symbols(backtraceFrames, frameCount);
    for (int i = 0; i < frameCount; i++) {
        [stackSymbols addObject:[NSString stringWithUTF8String:symbols[i]]];
    }
    free(symbols);
    
    // 构建报告
    NSMutableDictionary *report = [NSMutableDictionary dictionary];
    report[@"type"] = @(CrashTypeSignal);
    report[@"signal"] = [self stringForSignal:signal];
    report[@"signalCode"] = @(signal);
    report[@"stack"] = stackSymbols;
    report[@"timestamp"] = @([[NSDate date] timeIntervalSince1970]);
    report[@"appVersion"] = [[NSBundle mainBundle] objectForInfoDictionaryKey:@"CFBundleShortVersionString"];
    report[@"systemVersion"] = [[UIDevice currentDevice] systemVersion];
    report[@"deviceModel"] = [self deviceModel];
    
    [[CrashCollector sharedInstance] saveCrashReport:report];
    
    // 显示Alert
    [self showCrashAlert:report];
    
    // 恢复默认信号处理
    signal(signal, SIG_DFL);
    raise(signal);
}

static void handleCrash(CrashContext *context, CrashType type) {
    // 收集堆栈
    void *backtraceFrames[128];
    int frameCount = backtrace(backtraceFrames, 128);
    NSMutableArray *stackSymbols = [NSMutableArray array];
    char **symbols = backtrace_symbols(backtraceFrames, frameCount);
    for (int i = 0; i < frameCount; i++) {
        [stackSymbols addObject:[NSString stringWithUTF8String:symbols[i]]];
    }
    free(symbols);
    
    // 构建报告
    NSMutableDictionary *report = [NSMutableDictionary dictionary];
    report[@"type"] = @(type);
    report[@"exceptionCode"] = @(context->exceptionCode);
    report[@"exceptionSubcode"] = @(context->exceptionSubcode);
    report[@"exceptionAddress"] = [NSString stringWithFormat:@"%p", context->exceptionAddress];
    report[@"stack"] = stackSymbols;
    report[@"timestamp"] = @([[NSDate date] timeIntervalSince1970]);
    report[@"appVersion"] = [[NSBundle mainBundle] objectForInfoDictionaryKey:@"CFBundleShortVersionString"];
    report[@"systemVersion"] = [[UIDevice currentDevice] systemVersion];
    report[@"deviceModel"] = [self deviceModel];
    report[@"threadContext"] = [NSString stringWithFormat:@"%p", context->threadContext];
    
    [[CrashCollector sharedInstance] saveCrashReport:report];
    
    // 显示Alert
    [self showCrashAlert:report];
}

#pragma mark - Alert & Reporting

+ (void)showCrashAlert:(NSDictionary *)report {
    dispatch_async(dispatch_get_main_queue(), ^{
        CrashCollector *instance = [CrashCollector sharedInstance];
        if (instance.alertBlock) {
            instance.alertBlock(report, ^(BOOL shouldContinue) {
                // 用户决定是否继续
                if (!shouldContinue) {
                    exit(0);
                }
            });
        }
    });
}

+ (NSString *)stringForSignal:(int)signal {
    switch (signal) {
        case SIGABRT:  return @"SIGABRT";
        case SIGILL:   return @"SIGILL";
        case SIGSEGV:  return @"SIGSEGV";
        case SIGFPE:   return @"SIGFPE";
        case SIGBUS:   return @"SIGBUS";
        case SIGPIPE:  return @"SIGPIPE";
        case SIGTRAP:  return @"SIGTRAP";
        default:       return [NSString stringWithFormat:@"Signal(%d)", signal];
    }
}

+ (NSString *)deviceModel {
    struct utsname systemInfo;
    uname(&systemInfo);
    return [NSString stringWithCString:systemInfo.machine encoding:NSUTF8StringEncoding];
}

#pragma mark - Helper Methods

- (NSString *)reportFilePath:(NSString *)reportId {
    NSArray *paths = NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, 
                                                         NSUserDomainMask, 
                                                         YES);
    NSString *documentsPath = [paths firstObject];
    NSString *crashDir = [documentsPath stringByAppendingPathComponent:@"CrashReports"];
    
    NSFileManager *fileManager = [NSFileManager defaultManager];
    if (![fileManager fileExistsAtPath:crashDir]) {
        [fileManager createDirectoryAtPath:crashDir 
               withIntermediateDirectories:YES 
                                attributes:nil 
                                     error:nil];
    }
    
    return [crashDir stringByAppendingPathComponent:[NSString stringWithFormat:@"crash_%@.json", reportId]];
}

@end
```

## ⚠️ 注意事项

1. **Mach 异常处理**：在 `catchMachException` 中必须返回 `KERN_FAILURE`，否则系统不会继续传递异常，可能导致应用卡死。

2. **内存管理**：崩溃处理中避免使用 `malloc` 或 `new` 分配内存，因为此时堆可能已经损坏。尽量使用栈内存或预分配的内存。

3. **信号安全性**：`signalHandler` 中只能调用异步信号安全的函数（如 `write`、`backtrace`），不能调用 Objective-C 方法。

4. **调试符号**：Release 包需要保留 `.dSYM` 文件用于符号化堆栈。

5. **App Store 审核**：确认你的崩溃收集行为符合隐私政策，不要在报告中包含用户敏感信息。

## 📋 iOS 中常见 Signal 信号详细解析

以下这7 种信号是 iOS 应用中最常见的崩溃信号。它们各自代表不同类型的底层错误，理解它们的含义对于定位和修复崩溃至关重要。

### 1. SIGABRT (Signal Abort) - 主动中止

**含义**：程序主动调用 `abort()` 函数或 `assert()` 断言失败时触发的信号。

**触发场景**：
- 断言失败：`NSAssert(NO, @"error")`、`NSCAssert`
- 显式调用：`abort()`、`exit()`
- 未捕获的 C++ 异常
- 内存管理错误：过度释放对象（`release` 一个已释放的对象）

**典型案例**：
```objective-c
// 断言失败
NSAssert(1 == 2, @"逻辑错误");  // 触发 SIGABRT

// 过度释放
NSObject *obj = [[NSObject alloc] init];
[obj release];
[obj release];  // 第二次 release 触发 SIGABRT
```

**排查要点**：
- 查看崩溃日志中的 `reason` 字段
- Xcode 控制台通常有详细的错误信息
- 最常见的是 `-[NSObject(NSObject) doesNotRecognizeSelector:]`（调用未实现的方法）

---

### 2. SIGILL (Signal Illegal Instruction) - 非法指令

**含义**：CPU 执行了非法或未定义的机器指令。

**触发场景**：
- 代码损坏或二进制文件不完整
- 跳转到无效的函数指针
- CPU 不支持当前指令集（例如在旧设备上运行新指令）
- 堆栈溢出导致代码段被覆盖

**典型案例**：
```objective-c
// 函数指针指向无效地址
void (*invalidFunction)() = (void (*)())0x00000000;
invalidFunction();  // 触发 SIGILL
```

**排查要点**：
- 通常非常罕见
- 检查是否使用了新的 ARM 指令（如 ARM64 特有指令）
- 检查代码签名和二进制完整性
- Xcode 的 Address Sanitizer 可能无法捕获（发生在更底层）

---

### 3. SIGSEGV (Signal Segmentation Violation) - 段错误

**含义**：访问了**不存在的内存地址**或**没有权限访问的内存区域**。这是最常见的崩溃信号之一。

**触发场景**：
- 访问空指针（`NULL` 或 `nil`）
- 访问已释放的对象（野指针）
- 栈溢出（无限递归）
- 数组越界（访问超出分配的内存）
- 写入只读内存区域

**典型案例**：
```objective-c
// 空指针访问
NSString *str = nil;
[str length];  // 在 Objective-C 中不会崩溃（nil 消息静默处理）

// 但是 C 指针会崩溃
char *ptr = NULL;
*ptr = 'a';    // 触发 SIGSEGV

// 野指针
NSObject *obj = [[NSObject alloc] init];
[obj release];
[obj description];  // 访问已释放对象触发 SIGSEGV

// 栈溢出
void recursiveFunction() {
    recursiveFunction();  // 无限递归
}
recursiveFunction();  // 触发 SIGSEGV (栈溢出)
```

**排查要点**：
- 使用僵尸对象检测（Zombie Objects）
- 启用 Address Sanitizer
- 检查 `EXC_BAD_ACCESS` 崩溃日志
- 重点关注 `release`、`dealloc` 相关代码

---

### 4. SIGFPE (Signal Floating Point Exception) - 浮点异常

**含义**：浮点运算错误，包括整数除以零。

**触发场景**：
- 整数除以零
- 浮点数溢出或下溢
- 非法的浮点操作（如 `sqrt(-1)`）
- 浮点数格式错误

**典型案例**：
```objective-c
// 整数除以零（注意：不同 CPU 可能表现不同）
int a = 10;
int b = 0;
int c = a / b;  // 触发 SIGFPE

// 浮点数除以零（在某些环境下不会崩溃，而是返回 inf）
float x = 10.0;
float y = 0.0;
float z = x / y;  // 返回 inf，不一定崩溃

// 但某些情况会触发
double d = sqrt(-1.0);  // 可能触发 SIGFPE
```

**排查要点**：
- 检查所有除法运算
- 验证除数不为零
- 检查数学函数（`sqrt`、`log`、`asin` 等）的参数合法性
- 在 ARM 架构上，整数除以零通常触发 SIGFPE

---

### 5. SIGBUS (Signal Bus Error) - 总线错误

**含义**：内存访问存在**对齐问题**或访问的物理内存地址无效。

**触发场景**：
- **内存对齐错误**：访问未正确对齐的内存地址
- 访问映射到不存在的物理内存
- 内存映射文件（mmap）被截断或损坏
- 硬件总线错误（非常罕见）

**典型案例**：
```objective-c
// 内存对齐错误（ARM 架构常见）
// ARM 要求 4 字节对齐
char buffer[10];
int *intPtr = (int *)(buffer + 1);  // 未对齐地址
*intPtr = 100;  // 在 ARM 上触发 SIGBUS

// 更安全的写法
int alignedInt __attribute__((aligned(4)));
```

**排查要点**：
- 在 ARM64（iPhone 5s 及以后）上特别常见
- 检查结构体打包（`#pragma pack`）
- 检查内存操作（`memcpy`、指针转换）
- 使用 `__attribute__((aligned(n)))` 确保对齐
- 在 x86 模拟器上可能不会触发（x86 更宽容）

---

### 6. SIGPIPE (Signal Pipe) - 管道破裂

**含义**：向已关闭的管道、Socket 或 FIFO 写入数据。

**触发场景**：
- 网络 Socket 连接断开后继续写入
- 管道（Pipe）的另一端已关闭
- 文件描述符无效或已关闭
- 写入已断开的 TCP 连接

**典型案例**：
```objective-c
// Socket 网络操作
NSInputStream *inputStream;
NSOutputStream *outputStream;
// ... 建立连接

// 如果服务端关闭连接，客户端继续写入
[outputStream write:data maxLength:len];  // 触发 SIGPIPE

// 解决方案：忽略 SIGPIPE
signal(SIGPIPE, SIG_IGN);  // 让 write 返回错误而不是崩溃
```

**排查要点**：
- 检查网络请求的超时和重试逻辑
- 验证文件/网络操作前先检查状态
- iOS 开发中常见于 Socket 编程
- 通常通过设置 `SO_NOSIGPIPE` 或 `signal(SIGPIPE, SIG_IGN)` 处理

---

### 7. SIGTRAP (Signal Trap) - 断点/陷阱

**含义**：程序遇到了断点（Breakpoint）或陷阱指令，通常是调试器触发的。

**触发场景**：
- 调试器设置的断点
- `__builtin_trap()` 调用
- Swift 的 `fatalError()`、`preconditionFailure()`
- 断言失败（在 Debug 模式下）
- 未捕获的 Swift 错误（`throw`）

**典型案例**：
```objective-c
// 手动触发陷阱
__builtin_trap();  // 触发 SIGTRAP

// Swift
fatalError("Critical error")  // 触发 SIGTRAP

// Swift 可选值强制解包失败
let value = optionalValue!  // 如果为 nil，触发 SIGTRAP
```

**排查要点**：
- 在 Debug 模式下通常是断点
- Release 模式下检查 `assert`、`fatalError`、强制解包
- Swift 代码中特别常见
- 查看崩溃日志中的具体位置

---

## 📊 信号对比总结表

| 信号        | 错误类型      | 常见触发场景                   | 关键排查方向                    |
| ----------- | ------------- | ------------------------------ | ------------------------------- |
| **SIGABRT** | 主动中止      | 断言失败、过度释放、未捕获异常 | 查看错误消息、检查内存管理      |
| **SIGILL**  | 非法指令      | 代码损坏、无效函数指针         | 检查二进制完整性、CPU 兼容性    |
| **SIGSEGV** | 内存访问违规  | 空指针、野指针、栈溢出         | Address Sanitizer、僵尸对象检测 |
| **SIGFPE**  | 数学运算错误  | 除以零、非法数学运算           | 检查除法、数学函数参数          |
| **SIGBUS**  | 总线/对齐错误 | 内存对齐问题、无效物理地址     | 检查内存对齐、ARM 特殊处理      |
| **SIGPIPE** | 管道破裂      | 写入已关闭的 Socket/管道       | 设置 SIG_IGN、检查网络状态      |
| **SIGTRAP** | 断点/陷阱     | 调试断点、fatalError、断言     | 检查 Swift 强制解包、断言逻辑   |

---

## 🔍 实际应用中的处理策略

### 1. 优先处理的信号
```objective-c
// 最需要关注的 3 个信号
signal(SIGSEGV, signalHandler);  // 最常见的内存问题
signal(SIGABRT, signalHandler);  // 最常见的主动崩溃
signal(SIGBUS, signalHandler);   // ARM 设备上常见
```

### 2. 推荐的全局忽略
```objective-c
// 对于网络应用，建议忽略 SIGPIPE
signal(SIGPIPE, SIG_IGN);
```

### 3. 调试辅助
```objective-c
// 在 Debug 模式保留 SIGTRAP 用于调试
#ifdef DEBUG
    signal(SIGTRAP, signalHandler);  // 保留调试能力
#else
    signal(SIGTRAP, SIG_DFL);        // Release 模式恢复默认
#endif
```

### 4. 崩溃上报的优先级
```objective-c
- (NSString *)signalPriority:(int)signal {
    switch (signal) {
        case SIGSEGV: return @"CRITICAL";  // 最严重，立即上报
        case SIGBUS:  return @"HIGH";
        case SIGABRT: return @"HIGH";
        case SIGFPE:  return @"MEDIUM";
        case SIGILL:  return @"MEDIUM";
        case SIGTRAP: return @"LOW";
        case SIGPIPE: return @"LOW";      // 通常不影响核心功能
        default:      return @"UNKNOWN";
    }
}
```

## 💡 高级调试技巧

1. **符号化堆栈**：保存 `.dSYM` 文件，使用 `atos` 或 Xcode 符号化崩溃日志
2. **内存调试**：启用 Xcode 的 Zombie Objects、Address Sanitizer、Thread Sanitizer
3. **静态分析**：使用 Xcode Analyzer 提前发现潜在的内存问题
4. **运行时检测**：使用 `malloc_history`、`leaks` 命令行工具
5. **生产环境监控**：集成崩溃分析服务（如 Firebase Crashlytics、Bugly）

理解这些信号的本质，能够帮助你快速定位问题的根源，而不是简单地重新启动应用或等待用户反馈。
